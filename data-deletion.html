How to Request Data Deletion

If you have interacted with dieukhientv through Facebook and would like your personal data deleted, you may submit a deletion request by email.

Email: vudinhhung.cloud@gmail.com
Suggested subject: Data Deletion Request – dieukhientv

Please provide enough information for us to identify the relevant data, such as:

  • Your Facebook name
  • Your Facebook User ID or Page-Scoped User ID, if available
  • The Facebook Page you interacted with
  • The approximate date of your interaction

Please do not send passwords or other sensitive login information.

Facebook Webhook Data

dieukhientv currently uses Facebook Webhooks to receive events and information required for the application's functionality.

Depending on the event received from Facebook, the application may process identifiers and event information necessary to handle interactions with Facebook Pages.

If Messenger functionality is added in the future, dieukhientv may process Messenger-related information according to the permissions granted to the application.

Removing Access from Facebook

  1. Log in to Facebook.
  2. Go to Settings & Privacy.
  3. Select Settings.
  4. Open Apps and Websites.
  5. Find dieukhientv, if listed.
  6. Select Remove or revoke the permissions granted to the application.

Removing access may prevent future access through the revoked Facebook permissions. To request deletion of data that may already have been stored, please contact vudinhhung.cloud@gmail.com.

Data That May Be Deleted

Where applicable, a valid deletion request may include deletion of data such as:

  • Facebook user identifiers
  • Page-scoped identifiers
  • Stored Facebook Webhook event data associated with the user
  • Messenger-related identifiers or interaction data if Messenger is enabled in the future
  • Application records associated with Facebook interactions

Certain information may be retained where required by applicable law or for legitimate security purposes.
